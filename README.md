# Lew3l1 Mods

Personal portfolio of **Daniil / Lew3l1** as a Twitch moderator.

## Focus
- Twitch chat moderation
- Chat bots and automation
- Channel setup
- 50+ channels in overall moderation experience

## Pages
- `/index.html` — landing page
- `/channels.html` — Twitch moderation portfolio
- `/about.html` — profile and experience
- `/contact.html` — collaboration contacts

## Data
The initial `data/streamers.json` dataset is based on the supplied streamer list. It currently contains 41 source entries. Detailed descriptions, avatars, roles and active/former statuses are intentionally left unfilled until confirmed.

## Design direction
Dark cinematic interface, restrained glass surfaces, large typography, responsive layout and accessibility-minded interaction inspired by the supplied Apple Design Skill.
